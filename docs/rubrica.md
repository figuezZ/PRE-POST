# Resumen operativo de la rubrica

| Criterio | Peso | Evidencia que debe producir el repositorio |
|---|---:|---|
| Correccion de ingenieria | 30 % | Hipotesis, unidades, ecuaciones, norma y ausencia de errores criticos |
| Validacion y confiabilidad | 20 % | Casos, tolerancias, pruebas, errores y reproducibilidad |
| Calidad del software | 15 % | Modulos, datos tipados, instalacion y control de versiones |
| Producto profesional | 15 % | Flujo, interfaz responsive, reportes y trazabilidad |
| Documentacion | 10 % | README, memoria, manual, referencias y limitaciones |
| Innovacion | 10 % | Extension util solo despues del nucleo obligatorio |

Bloqueos tecnicos: resultados sin unidades, confusion entre fuerza inicial y
efectiva, pruebas no ejecutables, casos no trazables, formulas distintas entre
interfaz y nucleo, o incumplimientos ocultos.
